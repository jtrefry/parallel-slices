# Support

## Questions and setup help

Open a [GitHub issue](https://github.com/jtrefry/parallel-slices/issues) and
include:

- operating system and architecture;
- Node.js, selected AI agent, Git, Docker Desktop, and package-manager versions;
- whether this is a new or existing Turborepo;
- the command that failed and its sanitized output; and
- whether Docker Desktop or the best-effort Rancher Desktop alternative is in
  use.

Remove credentials, tokens, private hosts, customer data, and proprietary source
before posting.

## Bugs

Use the bug-report issue form. Include the smallest reproducible fixture when
possible. A failure specific to Rancher Desktop should also be reproduced with
Docker Desktop before it is classified as a supported-runtime defect.

## Security

Follow [`SECURITY.md`](SECURITY.md). Never report a vulnerability publicly.
